This is the first assignment of the unit Introduction to Information Technology (4478).

The assignment is based on the automated pet feeder system designed to dispense pet foods to dogs and cats at a scheduled time.
This system also makes sure that the staffs are alerted if there are issues like shortage of foods and if the foods are not consumed be the pets.

It uses time based equipments, sensors to detect the availability and consumption of the food, timer, servo motor and finally the alarm to alert staffs.
These infrastructures are well designed and interconnected so that the system dispense food without any disruptions and issues.

Apart from the description, in order to help understand the system even better this project includes block diagram, algorithm, and flowchart. 
Such diagrams help to analyse and implement the system properly if it is to be brought into real-world implementation.
